# Visual Style References

A working library of visual style approaches in published board games. Use to help a designer name what they're shooting for, or to push them toward a sharper visual identity.

This is grounded in training-knowledge state of the hobby — for very recent releases, the user should look up current examples.

## Painted illustration, mid-detail, naturalistic

**Examples**: *Wingspan* (Beth Sobel — botanical illustration tradition), *Cascadia*, *Verdant*, *Earth*, *Meadow*.

Audience: cozy / nature-genre players. Mass-appeal beyond hobby gamers.
Strengths: warm, inviting, beautiful at a glance, photogenic on the box.
Watch-outs: easy to look generic if the artist isn't strong; the genre is crowded.

## Painted illustration, high-detail, dramatic

**Examples**: *Spirit Island*, *Dominant Species*, *Twilight Imperium 4* (some art direction), *Star Wars: Rebellion*.

Audience: thematic-game players, war / strategy crossover.
Strengths: cinematic, evocative, sells weight and seriousness.
Watch-outs: expensive (high-detail painted art runs hundreds to thousands per piece); easy to overcrowd box covers.

## Vector / flat illustration

**Examples**: *Sushi Go!*, *Welcome To...*, *Calico*, *Mottainai*.

Audience: family games, light hobby games, accessible audiences.
Strengths: cheap, scalable, distinctive, prints well at all sizes, friendly.
Watch-outs: looks light by default — wrong choice for heavy strategy games.

## Photographic / collage

**Examples**: *Detective: A Modern Crime Board Game*, *T.I.M.E Stories* (mixed), *The Crew* (less photo-heavy but graphic).

Audience: investigation, narrative, modern-setting games.
Strengths: real-world grounded; conveys "this is now / this is real."
Watch-outs: photo collage can date quickly and feel cheap if rendered poorly.

## Iconographic, mechanical-first

**Examples**: *Concordia*, *Nucleum*, *Brass: Birmingham*, *Roads & Boats*.

Audience: heavy euro / 18xx players.
Strengths: clean, scales to complex games, looks "serious."
Watch-outs: barrier to mass-market appeal; the "ugly euro" reputation.

## Cartoon / illustrated character

**Examples**: *Munchkin*, *Coup*, *King of Tokyo*, *Quacks of Quedlinburg*.

Audience: family / casual / party.
Strengths: approachable, memorable characters, lots of merchandising potential.
Watch-outs: doesn't sell weight; can read childish to adult-only audiences if not handled well.

## Mythic / painted storybook

**Examples**: *Everdell* (Andrew Bosley — distinctive style), *Sleeping Gods* (Ryan Laukat), *Tales of Glory*.

Audience: mid-weight cozy / family / adventure crossover.
Strengths: emotionally evocative, builds a coherent world identity, sells campaigns.
Watch-outs: takes a strong lead artist whose style is identifiable; difficult to commission piece-by-piece from multiple artists.

## Retro / pulp / nostalgic

**Examples**: *Fury of Dracula* (3rd ed.), *Mansions of Madness* (Lovecraftian pulp), *Robinson Crusoe*, *Yellow & Yangtze*.

Audience: thematic players who love the source genre.
Strengths: leans hard into a specific aesthetic language; fans of the genre pick it up immediately.
Watch-outs: niche signal — if a buyer doesn't recognize the genre cues, the cover is opaque.

## Gritty / dark / horror

**Examples**: *This War of Mine: The Board Game*, *Nemesis*, *Mansions of Madness*, *Kingdom Death: Monster*.

Audience: horror / survival / thematic players.
Strengths: distinctive, sells weight and stakes.
Watch-outs: turn-off for cozy audiences; need to handle violence / horror tastefully for retail-distributed games.

## Modernist / abstract / graphic

**Examples**: *Azul*, *Hive*, *Patchwork*, *Tetris-style abstract designs*.

Audience: abstract gamers, design-conscious buyers, broader audiences than abstracts traditionally captured.
Strengths: looks elegant, ages well, photographs beautifully on shelves.
Watch-outs: doesn't sell theme; not the choice if theme is part of the appeal.

## Mixed media

**Examples**: Some hand-illustrated indie games, some Kickstarter-aesthetic projects.

Audience: indie / boutique buyers.
Strengths: distinctive, author-voice-driven, can be charming.
Watch-outs: takes confident execution; risk of looking amateur if not held together by strong art direction.

## Helping the designer pick

When a user is unsure of style, work backward from audience and theme:

- **Cozy nature theme + family audience** → painted naturalistic mid-detail or vector flat.
- **Heavy strategy + serious adult audience** → iconographic mechanical-first, or painted high-detail dramatic.
- **Light family / party** → cartoon character or vector flat.
- **Mythic / adventure** → mythic storybook or painted high-detail dramatic.
- **Modern detective / investigation** → photographic / collage, or mixed media.
- **Pure abstract** → modernist graphic.
- **Horror / dark / survival** → gritty painted, with care for taste.

Always validate by pulling 3+ specific game examples the user *likes*. The user's taste plus the audience's expectation should converge on one or two style families.

## When the user wants their game to "look like Game X"

That's a useful starting point but not a destination. Push the user past it:

- "What about Game X's look do you want to capture? Color? Mood? Detail level? Composition?"
- "What about Game X's look would *not* fit your game? Where would you diverge?"
- "Who painted Game X? Are they in your budget? If not, what's the alternative artist whose style overlaps?"

Imitating a game's look without understanding why it works produces a knockoff. Imitating with understanding — taking what fits, leaving what doesn't — produces a fresh game with a clear lineage.
