# Rulebook Structure Template

A working scaffold the designer can fill in. Adjust order to fit the game, but use this as the starting point.

## Title page / cover

```
[GAME TITLE]
[Tagline / evocative single line]

[Player count] | [Age] | [Time]
```

## Page 1 — Introduction (≤ 2 short paragraphs)

> Paragraph 1: The world / the player's role. Set scene in two or three sentences.
> 
> Paragraph 2: What you'll be doing in the game and why it's interesting. End with one sentence pointing to "Read the Game Overview on page X."

Keep this tight. Do not put rules here.

## Components

```
COMPONENTS

[Photo or labeled illustration of the box contents]

- [N] Game board(s)
- [N] Player boards
- [N] Cards (broken down by deck)
- [N] Tokens of [type], [color]
- [N] [Other components]
- [N] Player aids
- This rulebook
```

## Game Overview (½ to 1 page)

```
GAME OVERVIEW

In [Game Name], you are [role]. Each turn, you will [primary verb] in order to [primary goal].

The game lasts [N rounds / until X]. The player with [most/least Y] at the end wins.

To play, you'll need to:
- [Key sub-goal 1]
- [Key sub-goal 2]
- [Key sub-goal 3]
```

This page is the most important in the rulebook. If a player reads only this page, they should know the *shape* of the game.

## Setup

```
SETUP

1. Place the [main board] in the center of the table.
2. Shuffle the [deck name] and place it [location].
3. Each player chooses a color and takes:
   - [N] [item 1]
   - [N] [item 2]
   - 1 player aid
4. [Other setup steps in order.]
5. The [first player marker] goes to [criterion].
```

> **Diagram**: a labeled illustration of the table at end of setup.

## On Your Turn

```
ON YOUR TURN

When it's your turn, perform the following phases in order:

1. [Phase 1 name]
2. [Phase 2 name]
3. [Phase 3 name]

Each phase is detailed below.
```

Then a subsection per phase. Each subsection follows this pattern:

```
1. [PHASE NAME]

[1-2 sentences explaining what happens in this phase.]

To do this:
- [Specific instruction]
- [Specific instruction]

EXAMPLE: [Worked example with a small visual cue.]

Note: [Edge cases or exceptions, in a callout box.]
```

## Actions in detail

If your game has variable actions players choose between, give each its own subsection:

```
ACTIONS

[Brief intro to the action menu.]

ACTION: [NAME]
Cost: [resources spent]
Effect: [what happens]
Limit: [how often per turn / per game]
EXAMPLE: [Worked example.]

ACTION: [NAME]
...
```

## Combat / Movement / Sub-systems

For any sub-system that doesn't fit into the turn structure cleanly, give it its own clearly headed section:

```
COMBAT

When you [trigger condition], resolve combat as follows:

1. The attacker [step 1].
2. The defender [step 2].
3. Compare [outcome rule].
4. The loser [consequence].

EXAMPLE: [Diagrammed worked combat.]
```

## End of game and scoring

```
END OF THE GAME

The game ends when [trigger]. Complete the current round, then proceed to scoring.

SCORING

Each player scores:
- [N] points per [item]
- [N] points per [item]
- [Bonus: condition + points]

The player with the most points wins. In case of a tie: [tiebreaker rule].
```

## Reference / Appendix

This is where everything that *isn't* needed for a first read goes:

- **Solo mode** (with its own setup and rules)
- **Variants and house rules**
- **FAQ / edge cases**
- **Iconography reference**
- **Designer notes** (last)
- **Credits**
- **Index** (for any rulebook over ~12 pages)

## Quick-start guide (for heavier games)

A 1-2 page sheet for a simplified first game:

```
QUICK START

For your first game, ignore the [advanced rules X, Y]. Play with [simplified setup]. The full rules are in the main rulebook.

1. Set up as follows:
   - [Simplified setup steps]
2. On your turn:
   - [Simplified turn — fewer actions]
3. The game ends after [reduced trigger]. The player with the most [resource] wins.

Once you've played one game, read the full rules.
```

## Back-of-box copy

```
[Title]

[Evocative single line — what's the experience?]

[2-3 sentence pitch — what do you do, what's the hook, why care?]

[Player count] | [Age] | [Time] | [Weight indicator if used]

Designed by [Name] | Art by [Name]
```

The back of the box has 5 seconds to earn a buyer's pick-up. Treat it like the most important paragraph in the project. Match the voice to the audience — cozy game backs read very different from heavy euro backs.
